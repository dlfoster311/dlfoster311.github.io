Setup Guide

Recommended: Frigate NVR — If you want a full-featured solution with smart detection, recording, zones, and notifications, use Frigate instead. It runs locally, actually distinguishes cats from raccoons, and lets you mask areas like wind chimes. This dashboard is the lightweight alternative if you just want to view streams.

Using This Dashboard

This dashboard uses go2rtc to convert your Wyze RTSP streams into WebRTC so they play directly in the browser — no cloud, no subscription.

Step 1: Enable RTSP on Each Wyze Camera

  1. Open the Wyze app → tap your camera
  2. Go to Settings → Advanced Settings → RTSP
  3. Tap Enable RTSP and note the URL it shows you
  4. URL format: rtsp://username:password@192.168.1.x/live

Note: RTSP requires Wyze firmware that supports it. Some newer cameras need the beta RTSP firmware.

Step 2: Install go2rtc

Download the binary for your OS from the go2rtc releases page. It runs as a single executable with no dependencies.

Step 3: Create go2rtc Config

Create a file called go2rtc.yaml in the same folder as the binary:

streams:
  front_door: rtsp://wyzeuser:wyzepass@192.168.1.101/live
  backyard:   rtsp://wyzeuser:wyzepass@192.168.1.102/live

api:
  listen: :1984
  origin: "*"   # Required for browser access from this dashboard

Step 4: Run go2rtc

# Linux / macOS
./go2rtc

# Windows
go2rtc.exe

# Docker
docker run -d --name go2rtc \
  -p 1984:1984 \
  -v ./go2rtc.yaml:/config/go2rtc.yaml \
  alexxit/go2rtc

Step 5: Open This Dashboard

You need to serve this page over HTTP (not file://) so WebRTC works:

# From the cameras/ folder (Python 3)
python3 -m http.server 8080

# Then open: http://localhost:8080

Or put these files in go2rtc's www/ folder and it will serve them automatically at http://your-server:1984.

Step 6: Configure This Dashboard

  1. Click ⚙ Settings
  2. Set go2rtc Server Address to your server’s IP (e.g. 192.168.1.100:1984)
  3. Add each camera: give it a name and set the stream ID to match what’s in your go2rtc.yaml
  4. Click Save & Apply, then Connect All
